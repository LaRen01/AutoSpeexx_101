# AutoSpeexx-_101
CD: https://greasyfork.org/th/scripts/571011-autospeexx

นี่คือสรุปขั้นตอนการติดตั้ง การทำงาน และการแก้ไขปัญหา (Bug) ของสคริปต์ **AutoSpeexx** (ฉบับแปลไทย) ที่สามารถนำไปทำตามได้ทีละขั้นตอน:

---

### 1. ขั้นตอนการติดตั้ง

การติดตั้งสคริปต์นี้จะต้องทำผ่านส่วนขยายจัดการ UserScript บนเบราว์เซอร์ (แนะนำให้ทำบนคอมพิวเตอร์ผ่าน Google Chrome หรือ Microsoft Edge):

* **ขั้นตอนที่ 1: ติดตั้งส่วนขยาย Tampermonkey**
1. เข้าไปที่ร้านค้าส่วนขยายของเบราว์เซอร์ (Chrome Web Store)
2. ค้นหาและติดตั้งส่วนขยายชื่อ **Tampermonkey**

3. เมื่อติดตั้งเสร็จ ให้คลิกที่ไอคอน Tampermonkey มุมขวาบน แล้วตรวจสอบว่าเปิดใช้งานอยู่ รวมถึงไปเปิดสิทธิ์อนุญาต **"Allow User Scripts"** (อนุญาตให้ใช้สคริปต์) ในหน้าจัดการส่วนขยายให้เรียบร้อย


* **ขั้นตอนที่ 2: ติดตั้งสคริปต์ AutoSpeexx**
1. คลิกที่ไอคอน **Tampermonkey** มุมขวาบน แล้วเลือก **Dashboard (แดชบอร์ด)**
2. กดปุ่มสร้างสคริปต์ใหม่ (เครื่องหมายบวก `+`)
3. ลบโค้ดเริ่มต้นทั้งหมดออก แล้วคัดลอกโค้ดใน **==UserScript==.java** ที่ให้ไปมาวางแทนที่ทั้งหมด


4. กดบันทึก (**Save** หรือกด `Ctrl + S`)





---

### 2. ขั้นตอนการทำงาน (วิธีใช้งาน)

เมื่อติดตั้งเสร็จเรียบร้อยแล้ว สคริปต์จะทำงานอัตโนมัติบนแพลตฟอร์ม Speexx ตามขั้นตอนดังนี้:

1. **เข้าสู่เว็บไซต์ Speexx:** เปิดหน้าบทเรียน, วิดีโอ, หรือแบบฝึกหัดบนเว็บไซต์ Speexx (รองรับทั้งโดเมน `.cn` และ `.com`)


2. **แผงควบคุมปรากฏขึ้น:** สคริปต์จะแสดงหน้าต่างแผงควบคุม (Panel) เขียนว่า **AutoSpeexx** ขึ้นมาที่มุมขวาบนของจออัตโนมัติ


3. **เริ่มทำงาน:** กดปุ่มสีเขียว **"เริ่มทำงานอัตโนมัติ"** สคริปต์จะเริ่มทำการจำลองการเล่นวิดีโอ การกดแสดงเฉลย การส่งคำตอบ และกดปุ่ม Next ไปยังหน้าถัดไปเองตามเวลาที่ตั้งไว้


4. **การปรับแต่งตั้งค่า:** หากต้องการปรับเวลา สามารถคลิกที่แท็บ **"ตั้งค่า"** เพื่อกำหนดเวลาขั้นต่ำต่อข้อ (แนะนำค่าเริ่มต้นที่ 30 วินาทีขึ้นไปเพื่อป้องกันชั่วโมงเรียนผิดปกติ) แล้วกดปุ่มบันทึก



---

### 3. การแก้ปัญหาและบัคที่พบบ่อย (Troubleshooting)

* **ปัญหาที่ 1: สคริปต์ไม่รัน / แผงควบคุมไม่ขึ้น**
* **วิธีแก้:**
1. ตรวจสอบว่าเปิดสิทธิ์ **"Allow User Scripts"** ใน Tampermonkey แล้วหรือยัง


2. เช็กดูว่า URL ของหน้าที่คุณเปิดอยู่ตรงกับเงื่อนไขการทำงานหรือไม่ (ต้องอยู่ในหน้าบทเรียนหรือแบบฝึกหัด)


3. ลองกดรีเฟรชหน้าเว็บ (F5) อีกครั้ง






* **ปัญหาที่ 2: หน้าเว็บค้าง หรือหาปุ่ม Next ไม่เจอ / ไม่ยอมกดข้ามหน้าให้**
* **วิธีแก้:**
1. ให้ลองกดปุ่ม **"หยุดทำงานอัตโนมัติ"** บนแผงควบคุม แล้วกดรีเฟรชหน้าเว็บ 1 ครั้ง


2. ตรวจสอบในแท็บตั้งค่าว่ากำหนดเวลาหน่วง (Delay) สูงเกินไปหรือไม่ หรือปล่อยให้โหลดหน้าเว็บใหม่ให้เสร็จสมบูรณ์ก่อนแล้วค่อยกดเริ่มทำงานใหม่อีกรอบ




* **ปัญหาที่ 3: ชั่วโมงเรียน (Study Time) ไม่ขึ้น หรือระบบ Speexx ไม่บันทึกเวลา**
* **วิธีแก้:**
1. สคริปต์ถูกออกแบบมาให้มีระบบหน่วงเวลาขั้นต่ำต่อข้อ (ค่าเริ่มต้นคือ 30 วินาที) เพื่อจำลองความเร็วเสมือนมนุษย์


2. หากตั้งเวลาน้อยเกินไป ระบบของ Speexx อาจมองว่าทำเร็วกว่าปกติและไม่บันทึกเวลาให้ แนะนำให้คงค่าเวลาขั้นต่ำไว้ที่ 30 วินาทีขึ้นไป หรือเลือกเปิดใช้งานตัวเลือก *“พักในหน้าออกเสียงนานขึ้น”* ในหน้าตั้งค่า
